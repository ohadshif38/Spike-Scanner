# סורק מומנטום למניות קטנות

דשבורד שרץ בדפדפן ומדרג מניות אמריקאיות עם שווי שוק של עד 200 מיליון דולר, לפי ארבעה רכיבים:
ניתוח טכני, קטליזטורים מחדשות ומדיווחי SEC, פעילות ברשתות, ומבנה המניה (Float ושורט).

## התקנה והרצה

צריך Python 3.10 ומעלה. בתיקייה של הפרויקט:

```
pip install -r requirements.txt
streamlit run app.py
```

הדשבורד ייפתח בדפדפן בכתובת http://localhost:8501

## מקורות הנתונים (כולם חינמיים)

- **Yahoo Finance** דרך הספרייה yfinance: סינון לפי שווי שוק, מחירים, Float, שורט וחדשות. לא דורש מפתח.
  זו ספרייה לא רשמית, ולפעמים Yahoo משנה משהו והיא מפסיקה לעבוד עד עדכון. במקרה כזה: `pip install -U yfinance`.
- **SEC EDGAR**: דיווחים רשמיים (8-K, 13D, Form 4, הנפקות). חינמי, אבל ה-SEC דורש מייל לזיהוי; מזינים אותו בסרגל הצד.
- **ApeWisdom**: ספירת אזכורים של מניות ברדיט, כולל השוואה לאתמול. לא דורש מפתח.
- **StockTwits**: טרנדינג וקצב הודעות. לפעמים חוסם גישה אוטומטית; הסורק ממשיך גם בלעדיו.
- **Finnhub** (אופציונלי): כיסוי חדשות רחב יותר. נרשמים בחינם ב-finnhub.io ומדביקים את המפתח בסרגל הצד.

## הערות

- נתוני Yahoo בחינם מגיעים בעיכוב של כ-15 דקות. זה מספיק לזיהוי מגמות, לא למסחר של שניות.
- הזמן הכי מעניין להריץ הוא לפני פתיחת המסחר בארה"ב (בערך 14:00 עד 16:30 שעון ישראל) ובשעה הראשונה של המסחר.
- מילות המפתח והמשקלות שלהן נמצאות ב-`scoring.py`. כדאי לכוונן אותן לפי מה שאתם רואים שעובד.
- זה כלי לזיהוי סיגנלים, לא המלצת השקעה.

## הפעלה בלחיצה כפולה

- **Windows:** לחיצה כפולה על `start_windows.bat`
- **Mac:** קליק ימני על `start_mac.command` ואז "פתח" (בפעם הראשונה בלבד, בגלל אבטחת macOS)

בפעם הראשונה הקובץ מתקין את מה שצריך; בפעמים הבאות הוא פשוט פותח את הדשבורד.

## הפעלה בענן (בלי התקנה בכלל)

1. פותחים חשבון חינמי ב-github.com, יוצרים repository חדש ומעלים אליו את כל הקבצים מהתיקייה (Add file ← Upload files).
2. נכנסים ל-share.streamlit.io עם חשבון ה-GitHub, לוחצים Create app, בוחרים את ה-repository ואת הקובץ app.py.
3. אחרי דקה-שתיים מקבלים קישור קבוע שעובד מכל מחשב וגם מהטלפון.
